# NLP-Based Resume-Job-Description-Matching

An NLP-based system that compares a candidate's resume with a job description to identify matching skills, missing skills, and overall similarity.

## 📌 Project Overview

This project uses Natural Language Processing (NLP) techniques to analyze and compare resume content with job descriptions. It helps identify how closely a candidate's skills match the requirements of a job.

## 🚀 Features

- Resume and Job Description comparison
- Text preprocessing
- Skill matching
- Missing skill identification
- TF-IDF vectorization
- Cosine similarity
- Overall similarity score

## 🛠️ Technologies Used

- Python
- NLP
- Scikit-learn
- TF-IDF
- Cosine Similarity

## 🔄 Working

1. Input Resume
2. Input Job Description
3. Clean and preprocess the text
4. Convert text into TF-IDF vectors
5. Calculate cosine similarity
6. Identify matching and missing skills
7. Display the similarity score

## 📊 Output

The system provides:

- Matching Skills
- Missing Skills
- Similarity Score

## ⚠️ Limitation

The similarity score is only a decision-support measure. It does not replace human judgment in the recruitment process.
